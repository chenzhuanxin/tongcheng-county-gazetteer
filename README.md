# 通城县地名志（Tongcheng County Gazetteer of Place Names）

> 湖北省咸宁市通城县地名志 · 数字化成果库

## 项目简介

本仓库收录《通城县地名志》的完整数字化成果，包括：
- **完整可编辑 Word 版**：OCR 识别后生成的真实文本，双栏排版，可检索、可编辑
- **页面扫描 PDF 版**：原书逐页扫描打包，分无损原版与压缩查阅版两种

通城县位于湖北省东南部、湘鄂赣三省交界之处，隶属咸宁市。本志由通城县第二次全国地名普查领导小组办公室主持编纂，2020年12月通过湖北省地名文化丛书总编辑委员会终审验收，全志共收录地名 **6489 个**。

## 书籍结构（九篇）

1. **政区地名**：建置沿革、行政区划、乡镇村社区名称
2. **聚落地名**：城镇居民点、农村居民点名称
3. **自然地名**：山岭、河流、湖泊、洞泉、地片等
4. **单位类地名**：党政机构、事企业单位、群众组织
5. **历史地名**：已撤销公社/乡镇/村庄、已消亡的纪念地和风景名胜、已消亡的企业单位
6. **地名艺文**：诗联、歌谣赋、掌故传说
7. **地域特色品牌**：农产品（两头乌猪、茶叶、彩米）、工业产品（豆制品、矿泉水、酒、茶油）
8. **地名管理**：地名法规、地名普查、地名标志、管理机构
9. **附录**：地名形成规律、通名诠释、普查人员名单、后记

## 技术说明

- 原书为扫描版 PDF（无文字层），经逐页 OCR 识别后，使用 python-docx 库重建为高保真可编辑 Word 文档
- 重建过程中保留了原书的双栏/单栏排版、页眉页脚、章节层级、照片位置
- 页面扫描图保留在 `pdf_layout/pages/` 目录下（已清理 HD 冗余文件）
- 所有中文文字均设置了东亚字体（SimSun/SimHei）与西文字体（Times New Roman）
